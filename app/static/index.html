Cara menyiapkan link Figma
  1. Buka file Figma, klik kanan file di daftar lalu pilih Duplicate to drafts.
  2. Di salinan itu klik Share.
  3. Ubah akses menjadi "Anyone with the link can view".
  4. Salin link dan tempel di kolom ini.

Tanpa link Swagger atau Figma, generate tetap jalan; case terkait ditandai "Perlu verifikasi".
