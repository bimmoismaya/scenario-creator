Desain Figma (opsional; pilih salah satu cara)
Cara menyiapkan link Figma
  1. Buka file Figma, klik kanan file di daftar lalu pilih Duplicate to drafts.
  2. Di salinan itu klik Share.
  3. Ubah akses menjadi "Anyone with the link can view".
  4. Salin link dan tempel di kolom ini.
Cara menyiapkan file desain
  1. Di Figma, pilih frame lalu Export sebagai PNG, JPG, atau PDF.
  2. Boleh banyak frame sekaligus: kumpulkan dalam satu ZIP atau RAR.
  3. Maksimal 30 gambar/halaman per Generate, 50 MB per file. Cara ini tidak memakai kuota Figma MCP.

Hanya FSD yang wajib. Tanpa Swagger, Figma, atau folder Git, generate tetap jalan; case terkait ditandai "Perlu verifikasi".
